# Clean-Room and Intellectual Property Policy
Code: HP-POL-003 · Version 1.0 · Effective 2026-10-22 · Owner: Administration · Applies to: all research, code and content

## 1. Purpose
Joint Operations modifies a commercial game. Staying independent and respectful of others' rights is what keeps the project alive. This policy turns [legal.md](../legal.md) into working rules. It is not legal advice.

## 2. The game
- Every contributor uses their own legal copy of MGSV.
- **No game files** in the repository, issues, Discord or releases: no executables, archives, extracted scripts, textures, models, audio or text.
- Research describes game behavior **in our own words**, with archive paths and the game build, never pasted content.
- Reverse engineering is done for interoperability, on your own copy, as allowed by EU Directive 2009/24/EC Article 6 and similar laws. Results are used only for Joint Operations.

## 3. Other mods and projects
| Source | Rule |
|---|---|
| Open-source with a compatible license (for example IHHook, MIT; GzsTool, MIT) | May be reused with attribution, in a separate folder, with its license kept |
| Source without a license (for example Infinite Heaven) | Read for understanding only. Copy nothing |
| Licenses with restrictions we can't accept (for example Commons Clause) | Read for understanding only. Copy nothing |
| Closed tools (for example FoxBrowser) | Use on your machine. Never redistribute, never copy |

When you learn something from another project, credit it in the research note.

## 4. Konami's property
- No Konami logos, artwork, music or trademarks in our branding. The emblem and site art are original.
- Names like "Metal Gear Solid" are used only to describe what the mod works with, with the unofficial disclaimer.
- No commercial use: the mod is free, and donations (from 0.1) pay for hosting and development only ([ADR 0010](../decisions/0010-funding.md)).

## 5. Our own work
- The project license is set in [ADR 0005](../decisions/0005-license.md) (pending). Until it is accepted, the repository is visible but all rights are reserved.
- The website's design and text belong to Hound Protocol and are not covered by the code license unless stated.

## 6. Reporting
If you spot copied code, game files or a rights problem, tell the Administration Department privately. It is removed first and discussed after.
