# 0007: Host authority and roles
Status: Accepted · Date: 2026-10-21 · Deciders: project lead

## Decision
- The host plays Venom Snake and is authoritative for mission state, AI and world state.
- Other players join as soldiers chosen from the host's Mother Base roster. Each soldier is one player slot, numbered 1 to 16.
- Each player owns their own character's movement and camera.
- Host migration is out of scope until after 0.1.
