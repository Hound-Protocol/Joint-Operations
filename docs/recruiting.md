## Long version (forums, Reddit, modding communities)
**MGSV: Joint Operations: a 16-player co-op project for Metal Gear Solid V (PC)**

Hound Protocol is a community development team building MGSV: Joint Operations. The goal: up to 16 players in a single Metal Gear Solid V session, with Venom Snake as host and soldiers joining from the Mother Base roster. Players join and leave with proper in-game animations, not pop-ins.

What we are:
- A non-commercial, open, fan-made project. Forks welcome with credit.
- Built for Windows and for Linux via Proton.
- Documented, with a mod API for the community, plus a lobby app and web app planned.

What we are not:
- Affiliated with Konami. This is an unofficial fan project.
- A replacement for or competitor to any existing co-op mod. We work independently.

Where we are: Phase 0 (structure and documentation). Nothing playable yet. Research starts now.

Who we need:
- Reverse engineering and game hooks (C++, x64 debugging)
- Networking (UDP, state sync, Steam networking)
- Linux and Proton testers
- Windows testers
- Docs and wiki writers
- Web and app developers
- Moderators and community people

What we offer: a clear roadmap, written architecture, open decisions, and real ownership of your area. We do not promise a release date or payment. Donations, if opened, go to hosting and development only, and will be reported openly.
